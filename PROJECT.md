## 1. Идея

Мобильная стратегия на карте из шестиугольных плиток (по духу — «завоевание мира» из Роблокса,
но своя игра). Для публикации в RuStore (Android).

- Мир **вымышленный**, но по форме похож на настоящий: большой материк (как Евразия с Африкой),
  острова, два «американских» материка. Названия стран и городов придуманные.
- **Никаких поводов для споров**: нет реальных стран, флагов, дат, идеологий, чата,
  свободного ввода имён. Команды/страны — только вымышленные названия и цвета.
- Интерфейс повторяет **структуру** образца (что где находится), но стиль, иконки и тексты — свои.
  Чужие иконки/оформление не копируем (риск жалобы и снятия из магазина).
- Сначала **одиночная игра против ботов**. Онлайн (общий мир) — позже отдельным этапом.

## 2. Договорённости о разработке (важно для продолжения)

- Код пишет Claude в условиях жёстких бесплатных лимитов: **маленькие модули**, один шаг = один модуль,
  каждый файл примерно до 200 строк. После каждого шага игра должна запускаться.
- **Логика отдельно от картинки**: `scripts/core/` — чистая логика (без Node, без экрана),
  `scripts/view/` — отрисовка и управление. Так логика потом переедет на сервер без переписывания.
- Стиль кода (чтобы не ловить ошибки сборки, Godot у нас запускается только в облаке):
  - НЕ использовать `class_name`; подключать через `const X = preload("res://...")`.
  - Писать явные типы, когда значение берётся из нетипизированного Array/Dictionary
    (`var cn: Dictionary = arr[i]`, а не `var cn := arr[i]`).
  - Случайность только через `RandomNumberGenerator` с `seed` (воспроизводимость для онлайна).
  - Интерфейс собирается кодом; сцены минимальные (меньше шансов на ошибку в .tscn).
- Версия движка: **Godot 4.4.1**, рендер GL Compatibility (максимум совместимости с телефонами).
- Claude не может запустить Godot у себя: проверка = сборка в GitHub Actions + запуск APK на телефоне.
  Если сборка упала, пришлите Claude текст ошибки из лога (вкладка Actions → красный запуск → шаг, где крестик).

## 4. Как устроена карта

- Шестиугольники «вершиной вверх», нечётные ряды сдвинуты вправо. Индекс плитки `i = row * cols + col`.
- Размер плитки: константа `HEX_R` в `world_gen.gd` (сейчас 13 пикселей маски ≈ 1700 плиток суши).
  Больше число = крупнее плитки и меньше их. Для телефона плитка не должна быть мельче пальца.
- Страны: зёрна ставятся «самой дальней точкой» на каждом большом массиве суши (≈70 плиток на страну),
  потом страны растут от зёрен с шансом `GROW_CHANCE` (рваные границы).
  Острова меньше `SMALL_ISLAND_TILES` отдаются ближайшей стране.
- `assign_countries(world, seed)`: один seed = одна и та же карта. Кнопка «Новые границы» меняет seed.
- Позже страны можно рисовать вручную: вторая картинка, где каждая страна залита своим цветом.

## 5. Экономика (план, решения пользователя)

- Доходы: налоги (от населения и числа обычных плиток) + продукция промышленных плиток.
- Расходы: содержание армии (каждая дивизия стоит денег в день), содержание построек, позже флот.
- Типы плиток: обычная, **промышленная** (завод; строится за деньги, даёт производство, стоит денег
  на обслуживание), порт (на побережье), позже аэродром.
- Баланс «доходы − расходы»: при минусе армия слабеет/распускается.
- Производство: заводы распределяются ползунками между снаряжением армии и товарами для населения (доход).

## 6. Интерфейс (план; структура как у образца, стиль свой)

- Верхняя панель: деньги, заводы, население, дата.
- Правая колонка кнопок: армия, производство, исследования (потом дипломатия, флот, авиация).
- Левая колонка: только настройки и помощь. Магазин, рейтинг, события — не нужны.
- Окна: заголовок, крестик закрытия, список строк с ползунками; дерево исследований колонками.
- Нужно нарисовать свои иконки (SVG удобнее всего).

## 8. Сборка и запуск (кратко)

1. Файлы проекта лежат в репозитории GitHub `hex-world-game` (аккаунт jonhdik33).
2. Любая загрузка файлов запускает сборку (вкладка Actions). Или кнопка «Run workflow».
3. Готовый APK: Actions → последний запуск → внизу «Artifacts» → `hex-world-apk`.
4. APK скачать, распаковать zip, поставить на телефон (разрешить установку из неизвестных источников).
5. Для RuStore потребуется релизная подпись (ключ keystore хранить в секретах репозитория и
   в надёжном месте отдельно — потеря ключа = нельзя обновлять игру). Идентификатор пакета
   `com.hexworld.game` (в `export_presets.cfg`) после публикации менять нельзя — решить заранее.

## 9. Статус и известные риски

- Сборка Android в облаке настроена по образцу godot-ci и не проверена на этом проекте:
  вероятнее всего потребуется одна-две правки workflow по логу.
- Проверить на телефоне: хватает ли размера плитки для нажатия пальцем, не тормозит ли карта.
